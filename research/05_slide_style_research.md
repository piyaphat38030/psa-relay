## Design system locked for RELAY

| Element | Choice |
|---------|--------|
| Canvas | 16:9 (10" × 5.625") — standard executive |
| BG content | White `FFFFFF` |
| Title/close | Navy `051C2C` |
| Accent | McKinsey-like blue `0070AD` |
| Text | Charcoal `333333` / muted `666666` |
| Fonts | Arial (titles) + Calibri (body) — safe + consulting-common |
| Motif | Exhibit cards on light gray `F2F2F2`; no accent bars under titles |
| Footer | Source left · page right |

## Title-only storyline test (Pyramid)

1. RELAY — agentic connection continuity for PSA Code Sprint 2.0  
2. We recommend RELAY: detect connection risk, orchestrate recovery, gate high-impact moves  
3. Transshipment economics break when ETA/crane shocks put boxes inside the miss window  
4. Today’s recovery is fragmented — and fully autonomous action would be the wrong risk trade  
5. RELAY closes the loop with six agents, deterministic scoring, and human approval tokens  
6. Architecture separates domain truth from agent orchestration so the workflow is team-designed  
7. On the demo twin, approved plans clear or cut expected connection loss within one audited cycle  
8. Uncertainty and tool failure are handled with retries, fallback, and escalation — not silent improvisation  
9. Near-term impact is measurable; Sprinternship binds the same contracts to terminal systems  
10. RELAY is built to the brief’s four criteria — ready for live scenario walkthrough
